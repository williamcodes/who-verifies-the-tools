# 6. Related work and limitations

ReAct interleaves reasoning with actions, Toolformer learns when and how to call APIs, and ToolLLM builds tool-use training data from a large API collection [Yao et al., 2022; Schick et al., 2023; Qin et al., 2023]. AgentBench evaluates agents in interactive environments, while $\tau$-bench evaluates agents that converse with users and act through domain APIs [Liu et al., 2023a; Yao et al., 2024]. Both benchmarks take the visible tool output as part of the environment. Their evaluations do not test whether that output faithfully describes the tool's internal result.

LLM judges can track human preferences, but their verdicts remain sensitive to what they see and how it is presented. G-Eval prompts GPT-4 to score generated text, while MT-Bench compares LLM judgments with human preferences and reports position, verbosity, and self-enhancement biases [Liu et al., 2023b; Zheng et al., 2023]. Changing candidate-response order can reverse an LLM judge's comparison, and meaning-preserving prompt formats can produce large changes in task accuracy [Wang et al., 2023; Sclar et al., 2023]. Training-example order and the position of relevant evidence within a long context also affect model performance [Zhao et al., 2021; Liu et al., 2023c]. The warped formatting appears inside the tool output, before the agent writes an answer and the verifier judges it.

Groundedness metrics judge claims against supplied text. FEVER verifies claims against retrieved Wikipedia evidence, while FActScore measures the share of atomic facts supported by a knowledge source [Thorne et al., 2018; Min et al., 2023]. The hallucination literature defines faithfulness relative to provided source content [Ji et al., 2022]. RAG conditions generation on retrieved passages, and Ragas measures faithfulness to retrieved context [Lewis et al., 2020; Es et al., 2023]. When retrieved text passes through warped formatting, these methods cannot grade a boundary or qualification that the formatter omitted.

GroundEval records and deterministically scores agent trajectories while treating the tool layer as trusted ground truth [Flynt, 2026]. NabaOS checks agent claims against signed tool receipts, while conceding that a receipt remains valid when the data behind it is wrong [Basu, 2026]. FORCE-Bench uses rubrics to assess whether an agent's behavior is grounded in the returns supplied by its tools [Pauli et al., 2026]. AgentAssay detects behavioral drift across repeated runs instead of testing whether a formatter faithfully represents hidden state [Bhardwaj, 2026]. Anchor derives the instruction, oracle, and verifier from one specification, keeping those benchmark components aligned at creation [Ivanov and Rana, 2026]. ContractBench measures whether agents preserve tool-provided artifacts with syntactic fidelity as they carry them into later actions [Wang et al., 2026]. These methods begin their checks at the formatter boundary or farther downstream. None compares what the tool did with what its formatter's words tell the model.

**Limitations.** Our experiment covers four known failure families in a single production system. We selected cases adversarially from failures already identified in that system. The resulting rates measure performance under a stress test and provide no estimate of how often such defects occur.

The harness also removes capabilities available in deployment. An agent receives one tool output, answers once, and cannot enter a tool loop. It does not receive the production system prompt, which includes warnings aimed partly at these defects. Production agents can investigate further, although the incident that motivated this study shows that they do not always use that route.

Condition B uses the full shipped wording, which combines factual disclosures with instructions about how to handle them. Its measured effects therefore apply to that complete wording. The experiment does not isolate the effect of the disclosure fields by themselves.

Model consensus supplies the grades, with a human adjudicating disagreements. An AI assistant conducted the larger calibration regrade, while the independent human calibration covered 12 transcripts. We tested three model families; other models may behave differently.

The study makes no claim that any output was intentionally deceptive. The four disclosure fields need not exhaust what formatters can lose.

The audit-prompt exercise in Section 5 carries separate limits. The system's authors ran it using a prompt written by people who already knew the defects. For the runs on our own system's snapshot, Codex ran with persistent memory disabled, because we voided an initial launch after the agent read its own notes about the system. The Claude Code harness loads user-level instructions that cannot be disabled; we verified that those instructions contain nothing about the system. Adversarial model reviewers supplied the confirmation for the additional discrepancies on our own system; a human author reviewed a selection, not all. The two upstream findings received human review: we reviewed both before filing, and a maintainer's merge independently confirmed the OpenClaw fix. The exercise remains an unevaluated demonstration. The submission redacts links to the upstream issues for anonymous review.
