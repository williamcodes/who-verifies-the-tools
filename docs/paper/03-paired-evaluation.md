# 3. Paired evaluation

Section 2 described four families of formatter defects. This section describes the experiment that measures what those defects do downstream. We ask whether warped wording makes agents claim more and verifiers accept more. The experiment uses one comparison: take a real implementation result, render it two ways that differ only in disclosure, and observe what changes.

The two conditions differ only in the rendered text, so paired changes can be traced to that text. Condition A carries the warped wording (some using the same warped formatters which were actually in production) and Condition B the clear wording that ships today. B reports the same result while disclosing its scope, completeness, uncertainty, and provenance. For some families the shipped wording also instructs the model how to handle the disclosure, so the measured effect belongs to the complete text, not the disclosures alone. We study the wording fix because the formatter is this paper's subject, not because disclosure is always the best repair: for some defects a deeper fix, such as replacing the search cap with a more memory-efficient search algorithm, would be better engineering, and Section 5 discusses that choice. We freeze both texts by hash so nobody can revise them after seeing results. The authors wrote the scope and completeness fixes during the study; the uncertainty and provenance fixes predated it.

A case is one concrete tool call with a known correct answer. For example, one scope case searches one specific document for a term that occurs only past the million-character cap. We derive 40 cases, 10 per defect family, from reproduced database facts using deterministic rules. We use 8 cases to tune the instrument and exclude them from the primary analysis, so we cannot tune toward cases we practice on. The other 32 form the holdout set.^[Only 7 documents in the archive can support a scope case (long enough to exceed the cap, with a term occurring only beyond it), so with 10 scope cases, some documents serve more than one, and one document ended up with a case on each side of the tuning/holdout split. Since tuning could in principle have taught us something about that document, we committed in advance to also reporting the analysis with its holdout case dropped; Section 4 shows the results are unchanged.]

## Do agents claim more under warped wording?

\input{figure1}

Figure \ref{fig:agent} walks one case end to end. The agent test keeps everything except the tool-output wording constant. Each agent gets the same minimal research-assistant system prompt (shown in Figure \ref{fig:agent}) and the same question. We query `anthropic/claude-sonnet-5`, `openai/gpt-5.6-sol`, and `google/gemini-3.1-pro-preview` through an API aggregator. At temperature 1.0, each model produces 5 replicates for every case and condition, giving 1,200 runs. Every model output has a 4,000-token cap.

We freeze the grading rules after the pilot rounds and before the final experiment, so what counts as an error is settled before we see any answer it will be applied to. For each case, we list in advance which claims an answer may make and which are forbidden. A claim is forbidden when the database falsifies it or the evidence cannot support it. We accept hedging: a qualification anywhere in an answer keeps a claim from being forbidden when it covers the cited value. Two model graders from different vendors independently assess every answer for overclaim. When they agree, that shared verdict is the grade. When they disagree, an author decides using the claim lists, and we report how often that happened. Model graders and verifiers run at temperature 0.0 to minimize sampling variation. In the final pilot, an AI research assistant blindly regraded all 64 transcripts and matched the consensus on all 64. A human author independently graded 12 transcripts and matched it on 10/12; the two divergences were context failures that we repaired. After the full run, a human author blindly graded the preregistered 40-answer sample and matched the consensus on 35 of the 36 answers from the three models reported here (the other four sampled answers came from a model run not reported in this paper). In the one divergence, the human graded a hedged page estimate as an overclaim, a stricter reading than the frozen claim list allows.

## Do verifiers accept what warped wording tells them?

\input{figure2}

We measured the verifiers to see two things: causality and frequency. The first measurement (depicted in Figure \ref{fig:verif}) we call the fixed-answer measure. It asks whether the wording from the formatter alone changes verdicts. A false acceptance is a SUPPORTED verdict on an answer that contains a forbidden claim. For each case, we wrote one false answer asserting that case's forbidden claim, then showed that false answer to the verifier with tool output formatting from two versions of the formatter: the warped version and the clear version. Because nothing else varies, any change in the paired verdicts is caused by the formatter. All three verifiers judge every case under both conditions, producing 240 verdicts.

The second measurement of the verifier, the one for frequency, tells us how often false acceptance happens on the answers agents actually wrote. The setup matches Figure \ref{fig:verif} except that the judged answer is the agent's real one, and no verifier judges an answer from its own vendor. This measure does not show causality. The two wordings produce different answers, and a verifier can reject an answer for an unrelated defect.

An obvious objection is that these verifiers are simply weak, and stronger ones would catch the errors. So we tested it. We took 46 false answers agents actually wrote under the warped wording and judged each under every combination of two questions (supported vs. correct) and two evidence levels (tool output alone vs. with the verified facts). The two questions matter because a verifier asked only whether an answer is supported may rightly ignore facts beyond the tool output. Asking for correctness gives the added facts a fair chance. If the verifiers lacked ability, no combination would rescue them.

## Safeguards

Before we interpret any model behavior, we check that the two wordings really differ in the way we claim: disclosures are absent from every warped text, and are present in every clear one. A deterministic checker tests all 80 texts and flags 40/40 warped and 0/40 clear versions. We preregister exclusions for API errors, truncations, refusals, and grading failures, then count and report each type. We also seed the execution order and the 40 answers sampled for human grading so both can be reproduced.
