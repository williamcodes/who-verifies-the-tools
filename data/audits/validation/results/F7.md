Confirmed for translations produced by the default bulk pipeline.

- `generate_translation` (`generate_summaries_translations.py:84`) sends exactly `state["text"][:8000]` and configures a 4,000-token output limit. The returned text is stored unchanged in `english_transcript`.
- Both the `pipeline translate` command and the full pipeline invoke this generator through `cli.py` (`cli.py:124`).
- `_format_document_detail` (`rag.py:487`) labels the stored output `English translation (N chars)`. It warns only when the English output itself exceeds 8,000 characters. It never compares its length or provenance with the source transcript.
- A reproduction with a sentinel after source character 8,000 showed an 8,000-character prompt, no sentinel, and `max_tokens=4000`. A 60,000-character source paired with a simulated 7,000-character response produced no warning in the English section.
- The FTS index copies the stored `english_transcript` directly. Consequently, later material cannot be found through that field for records generated by this path. The original-language transcript and other indexed fields may still produce a hit.
- For a 60,000-character document, the model receives the opening 13.33%, not merely an excerpt hidden by the display formatter.

The scope is translation-path dependent. `translate_document` (`rag.py:1334`) sends up to 30,000 characters with a 16,000-token output limit. `translate_scans.py` translates page chunks, while `translate_text_fallback.py` sends the complete transcript. Therefore, the categorical wording does not describe every possible `english_transcript`, but the reported defect holds for the default bulk path and existing legacy translations that the newer missing-only pipelines preserve. The checkout contains no archive database, so the claim that outputs are “typically well under 8,000” could not be measured.

VERDICT: CONFIRMED — The default bulk pipeline stores translations made from only the first 8,000 source characters, and the formatter can present them without a source-completeness warning.
